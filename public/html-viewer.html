Saving, preview limits, and help

Your code saves only in this browser. Clearing browser data can erase it. Use Tools → Copy Code to keep a copy elsewhere. Clear Editor and Load Sample keep one previous version that you can restore.

The sandbox blocks popups, dialogs, camera, microphone, location, and some browser features (APIs), including storage and workers. External files may still load. Error notices show what the browser reports; they cannot explain every network problem.

If code stops the tab from responding, reload or close the tab. On a narrow screen, choose Editor or Preview to switch views. On a wide screen, drag the divider or use its arrow keys to resize the panels.
